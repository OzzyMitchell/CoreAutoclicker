Core Lexend is a 14,020-byte ASCII subset of [Lexend Regular](https://github.com/google/fonts/tree/main/ofl/lexend), renamed for this app.

License: [SIL OFL 1.1](OFL-Lexend.txt).

To rebuild the font, install fontTools and run:

```powershell
python tools/subset_font.py "Lexend[wght].ttf" assets/CoreLexend-Regular.ttf
```
